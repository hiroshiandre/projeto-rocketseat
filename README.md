## 🚀 Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- HTML5
- CSS3 (variáveis CSS, Flexbox e `backdrop-filter`)
- JavaScript
- Git e GitHub

## 💻 Projeto

O DevLinks é uma página no estilo "link na bio", com a foto de perfil, o nome de usuário e botões que levam ao portfólio, ao Instagram e ao LinkedIn.

Um botão no topo alterna entre o **tema escuro** e o **tema claro**. Ao clicar, o JavaScript adiciona ou remove a classe `light` no `<html>`, o que muda as cores, o fundo, o ícone do botão e também a foto de perfil.

## ▶️ Como executar

```bash
# clone o repositório
git clone https://github.com/hiroshiandre/projeto-rocketseat.git

# entre na pasta
cd projeto-rocketseat
```

Depois é só abrir o `index.html` no navegador, ou usar a extensão **Live Server** do VS Code.
